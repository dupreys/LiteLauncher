# LiteLauncher branding

| File | Use |
|---|---|
| `icon.svg`, `icon-256.png`, `icon-512.png` | App icon (source and PNG exports) |
| `../../src/LiteLauncher.App/Assets/LiteLauncher.ico` | Windows icon (16, 24, 32, 48, 64, 128, 256 px). Used by the `.exe`, the installer and shortcuts |
| `logo-horizontal-dark.png` / `.svg` | Logo for dark backgrounds |
| `logo-horizontal-light.png` | Logo for light backgrounds (dark "Lite") |
| `banner.png` | README header |
| `social-preview.png` | GitHub social preview (1280 x 640). Set it in the repository: *Settings > General > Social preview* |
| `../../packaging/Assets/` | Logos for the MSIX package |

Colours: icon background `#14171D`, edge `#343B46`, tiles `#3E444F`, accent green `#2EA043`, focus ring and light text `#F5F7FA`.
Font: Inter (Light for "Lite", Bold for "Launcher").

The icon is a 2x2 grid with one focused tile, the same idea as the launcher's own interface. The small sizes (16 to 32 px) use a
simplified drawing (bigger tiles, no focus ring) so they stay readable.

Do not combine the logo with the Xbox, Steam or Valve marks.
