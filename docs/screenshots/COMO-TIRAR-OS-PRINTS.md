# Prints para o README

Tire os prints com o launcher em tela cheia (tecla **Win + Shift + S** copia uma área da tela; cole no Paint e salve como PNG)
e salve nesta pasta com **exatamente** estes nomes. Depois copie as linhas do bloco abaixo para a seção
"Capturas de tela" do `README.md`.

| Arquivo | O que mostrar |
|---|---|
| `abertura-do-jogo.png` | Tela de abertura de um jogo (contagem e botões) |
| `jogando-agora.png` | A mesma tela com o jogo rodando (botão *Back to game*) |
| `menu-do-jogo.png` | Menu aberto com `Start` sobre um jogo |
| `conquistas.png` | Lista de conquistas |
| `biblioteca.png` | *My games & apps* com as abas e o botão de ordenação |
| `amigos.png` | Painel de amigos (cubra os nomes se quiser privacidade) |
| `energia.png` | Menu de energia |
| `configuracoes.png` | Configurações → Geral |
